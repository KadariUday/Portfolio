# 🚀 Kadari Uday - Portfolio

Welcome to my personal portfolio repository! This is a modern, highly interactive, single-page application built to showcase my journey as a Full-Stack Developer and AI Enthusiast. It features a sleek "vibecoding" dark-mode aesthetic with smooth scroll reveals and dynamic particles.

🔗 **Live Demo:** *(Add your hosted link here, e.g., https://kadariuday.vercel.app)*

---

## ✨ Features

- **Modern UI/UX:** Dark mode aesthetic with beautiful neon gradient accents (Purple, Blue, Emerald).
- **Interactive Animations:** Powered by `framer-motion` for buttery smooth scroll reveals and micro-interactions.
- **Dynamic Hero Section:** Features a stunning particle background (`@tsparticles/react`) and a realistic typing effect (`react-simple-typewriter`).
- **Responsive Design:** 100% mobile-friendly, adjusting seamlessly to any device.
- **Glassmorphism Nav:** A sticky, transparent navigation bar that blurs the background as you scroll.
- **Contact Form:** Integrated structure for reaching out, alongside direct links to GitHub and LinkedIn.

---

## 🛠️ Tech Stack

This project was bootstrapped with [Vite](https://vitejs.dev/) to ensure blazing fast local development and optimized production builds.

- **Frontend Framework:** React 18
- **Styling:** Tailwind CSS v4 (Using the new CSS variable-based `@theme` API)
- **Animations:** Framer Motion
- **Icons:** Lucide React & React Icons
- **Particles/Effects:** tsParticles
- **Deployment:** Ready for Vercel, Netlify, or Render

## 📦 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

Ensure you have Node.js installed on your machine.
- npm
  ```sh
  npm install npm@latest -g
  ```

### Installation

1. Clone the repository
   ```sh
   git clone https://github.com/KadariUday/Portfolio.git
   ```
2. Navigate into the directory
   ```sh
   cd Portfolio
   ```
3. Install NPM packages
   ```sh
   npm install
   ```
4. Start the development server
   ```sh
   npm run dev
   ```
